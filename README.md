# מתכנן טיולים

אפליקציית ווב חד-עמודית (SPA) לתכנון טיולים, בעברית ובפריסת RTL מלאה. מנהלת מספר טיולים שמורים, מסלול יומי מפורט, מעקב תקציב והוצאות, וצ'ק-ליסט לפני/במהלך הטיול — הכל נשמר מקומית בדפדפן (localStorage), ללא שרת/backend.

## הרצה

אין תהליך build ואין תלויות להתקנה. פשוט פותחים את [index.html](index.html) בדפדפן — האפליקציה עובדת גם ישירות מ-`file://` וגם מוגשת משרת סטטי כלשהו (למשל `npx serve .`).

## מבנה הפרויקט

```
index.html   — נקודת הכניסה, מכיל רק <div id="app"> ריק וקישור לגופן Rubik (Google Fonts)
app.js       — כל הלוגיקה: state, רינדור, אירועים, נתוני seed (~950 שורות)
style.css    — כל העיצוב, כולל design tokens כמשתני CSS ב-:root
```

אין framework, אין bundler, אין ספריות חיצוניות — JavaScript וניל טהור.

## פיצ'רים

### ניהול טיולים מרובים
- כותרת-על קבועה בראש העמוד ("תכנון הטיול הבא שלי"), ומתחתיה כותרת הטיול הפעיל עם תג שנה ואייקון עיפרון יחיד לעריכת שם הטיול ותאריך היציאה יחד (משנה שם ו/או יום/חודש/שנה, מעדכן את תוויות הימים במסלול תוך שמירה על כל התוכן שהוזן, ונשמר/מבוטל כיחידה אחת).
- מתחת לכותרת — בורר טיולים לבחירת טיול קיים וכפתור **+ NEW** ליצירת טיול חדש (שם, תאריך יציאה, מספר ימים, תקציב), ומתחת לבורר — טיימר ספירה לאחור חי (ימים:שעות:דקות:שניות) עד לתאריך היציאה של הטיול הפעיל, בצבע כתום בולט. אין כפתור שמירה ידני — ראו "שמירת נתונים" למטה.
- מעבר בין טיולים שומר אוטומטית את הטיול היוצא לפני טעינת החדש.

### טיול ברירת מחדל — "טיול לונדון"
מסלול מוכן ל-7 ימים (24–30/7) עם עשרות פעילויות אמיתיות (סוהו, פיקדילי, קובנט גארדן, לונדון איי, מופע אלאדין, קמדן מרקט, נוטינג היל, מלך האריות ועוד), כולל הוצאות ורשימת משימות לדוגמה. נטען אוטומטית בפעם הראשונה שאין נתונים שמורים.

### מסלול יומי (טאב "מסלול יומי")
- ניווט בין ימי הטיול דרך "כדורי" תאריך.
- הוספה, עריכה ומחיקה של פריטים ביום: שעה, קטגוריה (תחבורה / לינה / אטרקציה / אוכל), כותרת, תיאור ומחיר, דרך כפתור "הוסף פריט ליום זה" בכרטיס היום הנבחר.

### תקציב והוצאות (טאב "תקציב והוצאות")
- תקציב כולל הניתן לעריכה חופשית, מול סה"כ הוצאות בפועל ויתרה, עם התרעה ויזואלית בעת חריגה מהתקציב הכולל.
- פילוח הוצאות לפי קטגוריה (אוכל / תחבורה / אטרקציות / קניות): לכל קטגוריה מוצג הסכום שהוזן בפועל בלבד (ללא יעד/תקרה קבועים), עם בר יחסי לפי חלקה מסך ההוצאות, וגרף עוגה (donut) תואם-צבעים לצדו.
- הוספה ומחיקה של הוצאות בודדות עם קטגוריה, סכום והערה.

### צ'ק-ליסט (טאב "צ'ק-ליסט")
שתי רשימות משימות נפרדות — "לפני הנסיעה" ו"במהלך הטיול" — עם סימון השלמה, ספירת "הושלמו X מתוך Y", והוספה/מחיקה של משימות.

### נוספים
- כפתור הדפסה/שיתוף (`window.print()`).
- שמירה על מיקום הפוקוס והסמן בשדות טקסט למרות שהאפליקציה מרנדרת מחדש את כל העמוד בכל שינוי state.
- עיצוב רספונסיבי מלא, כולל התאמות למובייל (מודל הופך ל-bottom sheet, ניווט הופך לגלילה אופקית, מניעת זום אוטומטי ב-iOS).

## שמירת נתונים

כל הנתונים נשמרים במפתח `localStorage` יחיד בשם `tp-trips-v2`, המכיל את רשימת כל הטיולים השמורים ואת מזהה הטיול הפעיל. אין שרת ואין סנכרון בין מכשירים — הנתונים מקומיים לדפדפן הספציפי בלבד.

**שמירה אוטומטית, ללא כפתור:** כל שינוי באתר (הוספת/עריכת פריט, הוצאה, סימון בצ'ק-ליסט וכו') גורם ל-re-render, וכל re-render מפעיל טיימר שמירה (debounce של 600ms) שכותב את מצב הטיול הנוכחי ל-localStorage. אם הטאב נסגר/מתרענן ממש תוך כדי ה-debounce, מאזין ל-`beforeunload` מפעיל שמירה מיידית כדי שדבר לא יאבד.
